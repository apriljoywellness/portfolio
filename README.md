# Portfolio

Single-page portfolio site. No framework, no build step, no dependencies — one self-contained `index.html`.

Deployed on Cloudflare Pages.

## Local preview

Open `index.html` in a browser. That's it.

## Deploy

Cloudflare Pages, connected to this repo. Build command: none. Output directory: `/`.
Every push to `main` redeploys.

## Notes

- Light and dark mode both supported via `prefers-color-scheme`
- Mobile-first; single breakpoint at 560px
- Palette: deep plum, dusty rose, sage, muted gold, cream
